# B2B Site Studio: отчет по текущей версии

Дата проверки: 2 сентября 2026

Продакшен: http://45.91.238.213:3000/

## Что делает приложение сейчас

B2B Site Studio сейчас работает как первый экран кабинета для сбора базового брифа перед генерацией сайта. Экран не показывает выдуманную аналитику, товары, трафик или SEO-цифры. Он собирает только те данные, которые действительно нужны, чтобы понять задачу клиента перед созданием сайта.

Основной сценарий:

1. Клиент выбирает, кто он:
   - оптовая компания;
   - производитель;
   - дистрибьютор;
   - B2B-услуги.

2. Клиент выбирает тип сайта:
   - лендинг;
   - многостраничный сайт;
   - каталог с карточками;
   - SEO-сеть страниц.

3. Клиент выбирает модель сети:
   - один сайт;
   - сеть по регионам;
   - сеть по нишам;
   - отдельные домены.

После выбора приложение обновляет правую сводку "Текущий выбор", чтобы было видно, что уже понятно генератору.

## Как выглядит интерфейс

Интерфейс выполнен как темный рабочий кабинет:

- слева вертикальное меню разделов проекта;
- сверху заголовок "Создание сайта под клиента";
- в центре карточка "Выбор базовой модели сайта";
- внутри карточки три обязательные вкладки: "Кто клиент", "Тип сайта", "Сеть сайтов";
- справа блок "Текущий выбор" и список следующих блоков брифа.

Визуальный стиль:

- темный фон;
- оранжевый акцент для активного выбора и основных кнопок;
- циановые акценты для служебных бейджей и подсказок;
- компактные карточки без маркетинговой лендинговой подачи.

## Что изменено в последнем этапе

- Удалены фейковые показатели, которые не соответствовали реальному состоянию проекта.
- Удалены демонстрационные блоки аналитики, трафика, товаров, SEO-цифр и публикаций.
- В обзор добавлен чистый мастер первичного выбора сайта.
- Сделаны рабочие кнопки выбора для трех ключевых решений:
  - кто клиент;
  - какой тип сайта он заказывает;
  - нужен один сайт или сеть сайтов.
- Правая сводка теперь меняется при выборе вариантов.
- Добавлены поля первичного брифа:
  - название компании;
  - ниша или направление;
  - регион продаж;
  - главная цель;
  - цены;
  - страницы под товары;
  - количество сайтов;
  - контакты;
  - медиа и каталог.
- Добавлены правила для сети сайтов:
  - общий или отдельный телефон;
  - общие или уникальные фотографии;
  - один офис или разные адреса;
  - единый или разный каталог;
  - единый или региональный прайс;
  - один домен, поддомены, папки или отдельные домены;
  - единое или разное предложение для аудиторий.
- Исправлена мобильная адаптивность, чтобы вкладки и длинные тексты не расширяли экран.

## Что приложение должно делать дальше

Следующий логичный этап - превратить текущий первый экран в полноценный мастер генерации сайта:

1. Сохранять выбранные значения в состояние проекта.
2. Добавить следующие вкладки брифа:
   - товары и услуги;
   - структура страниц;
   - SEO;
   - дизайн;
   - публикация.
3. Сделать импорт товаров из Excel/CSV.
4. Добавить генерацию структуры сайта на основе выбранного типа.
5. Добавить отдельные настройки для сети сайтов:
   - данные общие для всей сети;
   - данные уникальные для каждого сайта;
   - региональные страницы;
   - домены и поддомены.
6. Добавить сохранение проекта и историю изменений.
7. Добавить режим предпросмотра сгенерированного сайта.
